# Учебное Django-приложение с формами

Веб-приложение с регистрацией, авторизацией, отправкой сообщений (в том числе через Ajax) и профилем пользователя.

## Функционал
- Регистрация с валидацией (совпадение паролей, уникальность email).
- Авторизация и выход из системы.
- Отправка сообщений с валидацией (не пустое, до 500 символов).
- Ajax-отправка сообщений без перезагрузки страницы.
- Профиль пользователя со списком его сообщений.
- Использование встроенной модели `User` и кастомной модели `Message`.
- Интерфейс на Bootstrap 5.
